# PPT Motion 이용 안내

적용 버전: 0.5.0 · 작성일: 2026-09-24

PPT Motion은 [MarcoYou/ppt-motion](https://github.com/MarcoYou/ppt-motion)에서 배포하는 발표자료 변환 도구입니다. 이 안내는 플러그인의 용도와 사용 조건을 설명합니다.

## 사용 범위

사용 권한이 있는 PPTX/PDF를 제공하고, 처리할 페이지와 필요한 효과를 지정해 사용하세요. 다른 사람의 저작권·개인정보·기밀을 침해하는 자료 처리나 공개에 이용해서는 안 됩니다. 입력 문서와 결과물의 권리는 해당 권리자에게 있으며, 프로젝트가 그 소유권을 취득하지 않습니다.

결과물은 HTML 발표자료입니다. 원본 PPTX에 PowerPoint 네이티브 애니메이션을 추가하는 기능이나 원본 수치·주장의 사실 검증을 제공하지 않습니다.

## 결과 확인

파일 구조 검사는 모든 자료에서 완벽한 시각적 동일성이나 설명의 정확성을 보장하지 않습니다. 발표·공유 전에 글꼴, 수치, 범례, 원본 비교와 모션을 확인하세요. 이미지로 합쳐진 차트나 변환 과정의 글꼴 차이 등은 추가 작업이 필요할 수 있습니다.

## 실행 환경과 비용

Python 의존성과 파일 실행 기능이 필요합니다. 설치된 앱·조직 정책·인터넷 연결에 따라 기능이 제한될 수 있습니다. 프로젝트는 자체 구독이나 결제를 요구하지 않으며, 사용하는 AI 서비스와 컴퓨팅 환경의 요금·약관은 별도로 적용됩니다. 제3자 패키지는 해당 패키지의 라이선스 조건을 따릅니다.

## 지원과 데이터

문제 제보와 개선 요청은 [GitHub Issues](https://github.com/MarcoYou/ppt-motion/issues)를 이용하세요. 지원 응답 시간이나 모든 파일 형식의 호환성을 보장하지는 않습니다. 파일의 처리·보관·공유 범위는 [개인정보 및 데이터 처리 안내](privacy.md)를 참고하세요.
