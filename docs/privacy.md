# PPT Motion 개인정보 및 데이터 처리 안내

적용 버전: 0.5.0 · 작성일: 2026-09-24

PPT Motion은 사용자가 제공한 PPTX/PDF를 실행 환경 안에서 읽고 HTML 발표자료를 만드는 스킬과 Python 도구입니다. 프로젝트 연락 창구는 [MarcoYou/ppt-motion Issues](https://github.com/MarcoYou/ppt-motion/issues)입니다.

## 처리하는 파일

- 사용자가 선택한 PPTX/PDF, 추출된 글·도형·차트 정보, 페이지 이미지.
- 효과와 강조를 지정하는 계획·설정, 원본 보존 확인용 해시, 생성된 HTML.
- 설치 스킬의 파일 목록·해시와 Python 런타임 캐시.

로컬 Codex·Claude Code에서는 해당 컴퓨터의 작업 폴더에서 처리합니다. ChatGPT 또는 Claude의 클라우드 실행 환경에 파일을 첨부하면 그 제공자의 서비스와 설정에 따라 처리됩니다. PPT Motion이 제공자의 보관·학습·보안 정책을 변경하지는 않습니다.

## 외부 전송

PPT Motion 엔진에는 프로젝트 운영자로 원본 자료를 전송하는 서버, 계정 등록, 광고 또는 분석 추적 기능이 없습니다. 첫 설치 시 GitHub에서 스킬을 받거나 Python 패키지 저장소에서 의존성을 내려받을 수 있습니다. 이런 연결에는 각 서비스의 일반적인 접속 정보 처리가 적용됩니다.

완성된 HTML은 슬라이드 내용과 원본 비교 이미지를 포함합니다. 따라서 HTML을 다른 사람에게 보내거나 호스팅하면 해당 내용도 함께 공개됩니다. 엔진은 결과물을 자동으로 외부에 게시하지 않습니다.

## 보관과 삭제

원본 사본, 추출물과 결과는 사용자가 지정한 작업 폴더에 남습니다. 설치 백업과 런타임 캐시도 로컬 또는 해당 실행 환경에 남을 수 있습니다. 보관이 필요 없으면 해당 폴더를 삭제할 수 있습니다. 클라우드에 첨부한 파일·대화의 삭제는 해당 제공자의 기능과 정책을 따릅니다.

공개 GitHub 이슈에는 발표 원본, 개인정보, 인증정보를 첨부하지 마세요. 문제를 재현할 수 있는 가상 데이터나 민감한 내용을 제거한 예제로 문의할 수 있습니다.
